# Contributing to µSystems

> **Open Source, Closed Contribution.**

µSystems is built on a strict first-principles philosophy: zero external dependencies, minimal footprints, and direct hardware interaction.

To preserve the absolute architectural integrity, performance standards, and security guarantees of the stack, **we do not accept external pull requests or code contributions.**

---

### How to Contribute

While code contributions are closed, **security research and bug disclosures are highly encouraged.**

#### 1. Reproducible Bug Reports
If you find a bug, edge case, or crash:
* Open an **Issue** with a clear description, minimal reproduction steps, and complete environment details.
* Do not submit a Pull Request with a fix. All patches are engineered and applied in-house to maintain code consistency.

#### 2. Vulnerability Research & Security Disclosures
If you discover a security vulnerability:
* Submit a report via **GitHub Security Advisory** under the respective repository.
* Every verified security report or bug fix will receive **explicit credits and public shoutouts** in the release notes, commit logs, and documentation.
* Where applicable, vulnerabilities will be coordinated via GitHub Advisory to issue official **CVE IDs** with proper attribution to the reporter.
